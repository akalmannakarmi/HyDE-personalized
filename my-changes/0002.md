# Extend hypridle timeouts & remove suspend

Hypridle idle timeouts were drastically increased so the system doesn't interfere during active use. Suspend listener removed entirely.

## Changes

| Action | Before | After |
|---|---|---|
| Dim display | 60s | 1hr (3600s) |
| Lock session | 120s | 3hr (10800s) |
| DPMS off | 300s | 3hr (10800s) |
| Suspend | 500s | **Removed** (never) |

## File

`Configs/.config/hypr/hypridle.conf` — all four `listener` blocks updated.
